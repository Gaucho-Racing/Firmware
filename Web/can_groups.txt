# Functional groupings for the Graph View physical-bus rendering.
# Each group header is "GROUP NAME: side" where side is one of:
#   top     — group sits above the bus
#   bottom  — group sits below the bus
#   bus     — group members render on the bus spine itself
# Nodes not listed in any group fall into an implicit "Other" group
# on the bottom side.
# "Debugger" and "ALL" are auto-placed on the bus spine.
# Lines starting with # are comments. Blank lines are ignored.
# Node names must exactly match GR ID entries in GRCAN.CANdo (same
# convention as can_topology.txt).
